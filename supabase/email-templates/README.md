# Auth email templates

Branded Onusmu emails for Supabase Auth, Greek first and English below (Supabase has one
template per email type, no per-language versions). Generated by `build.py`: edit the text
there and run `python build.py .`, rather than editing the HTML by hand.

Paste each file into **Supabase → Authentication → Emails → Templates**, with its subject:

| Template in Supabase   | File                    | Subject |
|------------------------|-------------------------|---------|
| Confirm sign up        | `confirm-signup.html`   | Επιβεβαίωσε το email σου · Confirm your email |
| Invite user            | `invite-user.html`      | Πρόσκληση στο Onusmu · You’re invited to Onusmu |
| Magic link or OTP      | `magic-link.html`       | Σύνδεση στο Onusmu · Sign in to Onusmu |
| Change email address   | `change-email.html`     | Επιβεβαίωσε το νέο σου email · Confirm your new email |
| Reset password         | `reset-password.html`   | Επαναφορά κωδικού · Reset your password |
| Reauthentication       | `reauthentication.html` | Ο κωδικός επιβεβαίωσης · Your verification code |

The logo is loaded from `https://onusmu.com/assets/emblem-96.png`, so keep that file on the website.
